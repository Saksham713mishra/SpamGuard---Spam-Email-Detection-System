Project Overview

Inside the SpamGuard Platform

A machine learning based web application built to classify suspicious emails quickly and reliably using an ensemble workflow.

Core Stack Flask + ML

What This App Solves

SpamGuard helps identify whether incoming email content is likely spam or legitimate. It is designed for quick manual checks and lightweight dashboard monitoring in one place.

The system combines text preprocessing, TF-IDF vectorization, and multiple classifiers to produce robust predictions for real-world messaging scenarios.

Technology Stack

  • Python and Flask backend service
  • Scikit-learn classification models
  • NLTK text preprocessing utilities
  • Bootstrap + custom responsive UI
